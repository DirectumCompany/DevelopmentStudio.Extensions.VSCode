# Расширение Development Studio для VS Code

## Описание

Расширение **Development Studio** предназначено для повышения удобства разработки решений на платформе Sungero.

## Возможности

### Удобная навигация

Расширение предоставляет возможность навигации по коду на C# к исходному коду (вместо сгенерированных платформой оберток):
- Public и Remote функций.
- Структур и их свойств.
- Строк ресурсов (переход к файлу .resx).
- Запросов к БД (переход к файлу .sql).

### Добавление сообщения в ресурсы

Расширение предоставляет возможность добавить строковую константу в ресурсы через вызов команды `sungero.createResourceFromText`.

## Горячие клавиши

- `Ctrl+Alt+R`: Показать окно просмотра ресурсов и запросов, связанных с текущим символом.
- `Ctrl+Alt+N`: Добавить строковую константу в ресурсы.

## Требования

- Visual Studio Code версии 1.89.1 или выше.
