# Сборка и установка

До сборки необходимо убедиться, что установлены:

- Node.js v20, рекомендуемая версия - 20.11.0,
- npm.

## Сборка

Для сборки нужно выполнить:

1. `npm i` - команда установить зависимости проекта
2. `npm run compile` - команда соберет проект

## Сборка в пакет vsix

Для сборки расширения в пакет vsix без изменения версии нужно запустить `package.bat` без параметров.
В результате в корне рабочей папки создастся пакет в формате {manifest.name}-{manifest.version}.vsix.

Для сборки расширения в пакет vsix с изменением версии нужно запустить package.bat с указанием версии, например `package.bat 0.0.2`.
В результате

- в корне рабочей папки создастся пакет в формате {manifest.name}-{version}.vsix,
- в git создается новый коммит с проставленной версией в файлах `package.json` и `package-lock.json`,
- на этот же коммит добавится тег с номером версии и префиксом `v`. Например, для 0.0.2 тег будет `v0.0.2`.
  Внимание! Созданный коммит не пушится при сборке. После сборки пакета и проверки, что пакет собрался нормально, нужно не забыть запушить созданный коммит.

## Установка из пакета vsix

Минимальная поддерживаемая версия VS Code 1.89.1.

Для установки:

- открываем VSCode,
- слева переходим в Extensions,
- вверху панели есть строка поиска, сверху справа от нее нажимаем на многоточие,
- выбираем "Install from vsix", выбираем нужный файл.

Либо можно установить с помощью команды:
`code --install-extension <путь_до_файла.vsix>`
