# Пререквизиты

До сборки необходимо убедиться, что установлены:

- Node.js v20, рекомендуемая версия - 20.11.0.
- npm.

## Реестр npm

В репозитории используется публичный реестр npm (`registry=https://registry.npmjs.org/`), чтобы проект собирался вне корпоративной сети.

Если вы работаете внутри сети компании и используете прокси-реестр, задайте его в пользовательском конфиге, а не в файлах репозитория:

```powershell
npm config set registry https://packages.directum.ru/repository/npm-proxy/ --location=user
```

Проверить действующий реестр: `npm config get registry`.

## Сборка

Для сборки нужно выполнить:

1. `npm i` - команда по установке зависимости проекта.
2. `npm run compile` - команда сборки проекта.

## Сборка в пакет vsix

Для сборки расширения в пакет vsix без изменения версии нужно запустить `package.bat` без параметров.
В результате в корне рабочей папки будет создан пакет в формате {manifest.name}-{manifest.version}.vsix.

Для сборки расширения в пакет vsix с изменением версии нужно запустить package.bat с указанием версии, например `package.bat 0.0.2`.
В результате:
- в корне рабочей папки создастся пакет в формате {manifest.name}-{version}.vsix,
- в git создается новый коммит с проставленной версией в файлах `package.json` и `package-lock.json`,
- на этот же коммит добавится тег с номером версии и префиксом `v`. Например, для 0.0.2 тег будет `v0.0.2`.

### Внимание! Созданный коммит не пушится при сборке. После сборки пакета и проверки, что пакет собрался без ошибок, нужно не забыть запушить созданный коммит.

## Установка из пакета vsix

Минимальную поддерживаемую версию VS Code смотри в README.md.

Варианты установки расширения:

1) Вручную:
- в редакторе кода VSCode перейдите на вкладку Extensions;
- рядом со строкой поиска нажмите на иконку с многоточием и в выпадающем списке выберите "Install from VSIX";
- в открывшемся окне выберите нужный файл.

2) С помощью команды: `code --install-extension <путь_до_файла.vsix>`.
