# Пререквизиты

До сборки необходимо убедиться, что установлены:

- Node.js 24.18.0 — версия, указанная в `engines.node` и проверенная при сборке.
- npm.

## Сборка

Для сборки нужно выполнить:

1. `npm i` - команда по установке зависимости проекта.
2. `npm run compile` - команда сборки проекта.

## Сборка в пакет vsix

Для сборки расширения в пакет vsix без изменения версии нужно запустить `package.bat` без параметров.
В корне рабочей папки будет создан пакет `development-studio-vscode-extension.vsix`.

Для сборки расширения в пакет vsix с изменением версии нужно запустить `package.bat` с указанием версии, например `package.bat 1.0.11`.
В результате:
- в `package.json` и `package-lock.json` проставляется указанная версия,
- в корне рабочей папки создастся пакет `development-studio-vscode-extension.vsix`.

### Внимание! Скрипт не создаёт коммит и не ставит тег. Изменения версии, `package.json` и `package-lock.json` нужно закоммитить и запушить вручную. Перед сборкой пакета добавьте запись о версии в `CHANGELOG.md`.

## Установка из пакета vsix

Минимальную поддерживаемую версию VS Code смотри в README.md.

Варианты установки расширения:

1) Вручную:
- в редакторе кода VSCode перейдите на вкладку Extensions;
- рядом со строкой поиска нажмите на иконку с многоточием и в выпадающем списке выберите "Install from VSIX";
- в открывшемся окне выберите нужный файл.

2) С помощью команды: `code --install-extension <путь_до_файла.vsix>`.
