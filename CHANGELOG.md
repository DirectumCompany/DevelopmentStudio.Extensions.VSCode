# Changelog

## [1.0.5] - 2026-07-27

- Обновлены версии библиотек.

## [1.0.4] - 2026-06-05

- Убрано ограничение на версию используемого расширения "ms-dotnettools.csharp".

## [1.0.3] - 2026-04-24

- Починен переход к ресурсной строке сущности при вызове команды "Go to Definition".

## [1.0.2] - 2026-02-20

- Добавлено ограничение на используемое расширение "ms-dotnettools.csharp": поддерживаются версии по 2.110.4 включительно. Если установлена более свежая версия, то будет отображено модальное окно с ошибкой.

## [1.0.1] - 2026-02-11

- Добавлена иконка для расширения.

## [1.0.0] - 2026-02-06

- Изменены имя, описание и changelog расширения.

## [0.0.4] - 2025-11-27

- Понижена совместимая версия VS Code с 1.95.0 до 1.89.1.
- Добавлен переход к ресурсной строке при вызове команды "Go to Definition".
- Добавлена новая настройка "sungero.resourseLanguageDefault" с возможными значениями "en" и "ru". В зависимости от значения этой настройки выполняется переход к нужному ресурсному файлу при вызове команды "Go to Definition".
- Добавлен переход к содержащему запрос файлу при вызове команды "Go to Definition".
- Добавлена новая настройка "sungero.queryTypeDefault" с возможными значениями "postgres" и "mssql". В зависимости от значения этой настройки выполняется переход к нужному файлу запроса при вызове команды "Go to Definition".
- В строку состояния добавлена кнопка для показа текущих значений настроек "sungero.resourseLanguageDefault" и "sungero.queryTypeDefault" и быстрой смены значений этих настроек.
- Добавлена новая команда "Sungero: Show peek view of the results" для показа списка файлов с найденными результатами для ресурсных файлов или файлов запросов. Горячие клавиши для вызова команды: Ctrl+Alt+R.

## [0.0.3] - 2025-08-15

- Команда "Sungero: Go to Definition" удалена.
- Настройка, в зависимости от значения которой регистрировался или нет дополнительный поставщик определений, удалена.
- Добавлена зависимость от расширения "ms-dotnettools.csharp". Перед регистрацией дополнительного поставщика определений ожидаем, когда проинициализируется  расширение "ms-dotnettools.csharp".
- Добавлено сообщение с предложением смены параметра "editor.gotoLocation.multipleDefinitions" на "goto" для автоматического перехода к "оригинальному" определению.

## [0.0.2] - 2025-08-13

- Добавлена новая команда "Sungero: Go to Definition" для перехода к "оригинальному" определению элемента. Вызвать команду можно с помощью `Ctrl+Enter`. 
- Добавлена новая опция, в зависимости от значения которой регистрируем или нет дополнительный поставщик определений. По умолчанию не регистрируем.


## [0.0.1] - 2025-07-28

- Прототип расширения. При вызове команды "Go to Definition" производится переход к "оригинальному" определению элемента.
